# Canon location

This project deliberately does not maintain a second Stele spec canon here. Behavioral requirements live in OpenSpec under `openspec/changes/` while proposed and under `openspec/specs/` after archive.

The copied Stele methodology in `docs/.stele/METHODOLOGY.md` is design reference material. This showcase adapts its stable IDs, code/test anchors, and guardrail concepts to OpenSpec's lifecycle as described in `PLAN.md`.
